# ClipBox

یک تاریخچهٔ کلیپ‌بورد کوچک و کیبوردمحور برای ویندوز، مک و لینوکس.

ClipBox در پس‌زمینه می‌ماند و هرچه را کپی می‌کنی نگه می‌دارد: متن، کد، لینک، تصویر، ویدیو، صدا، PDF و فایل. با یک میانبر بازش می‌کنی، جستجو می‌کنی و همان مورد را در پنجره‌ای که مشغولش بودی می‌چسبانی. تا وقتی خودت صدایش نکنی جلوی کارت را نمی‌گیرد.

پروژه اینجاست: [github.com/Amir-Pakdel/ClipBox](https://github.com/Amir-Pakdel/ClipBox).

## چه کار می‌کند

- تاریخچه را تا وقتی خودت پاک نکنی نگه می‌دارد. موارد سنجاق‌شده منقضی نمی‌شوند.
- در سینی سیستم می‌ماند. Esc و Alt+F4 و دکمهٔ بستن فقط پنجره را مخفی می‌کنند.
- در صورت تمایل، با روشن شدن سیستم اجرا می‌شود.
- وقتی بیکار است تقریباً پردازنده مصرف نمی‌کند.
- فقط یک نسخه همزمان اجرا می‌شود. اجرای دوباره فوراً خارج می‌شود.

## نصب در ویندوز

در PowerShell:

```powershell
irm https://raw.githubusercontent.com/Amir-Pakdel/ClipBox/main/install.ps1 | iex
```

همین دستور بار اول نصب می‌کند و بعداً برنامه را به‌روز می‌کند. فقط خودِ برنامه عوض می‌شود. تاریخچه و تنظیمات سرجایشان می‌مانند. اگر دانلود شکست بخورد، نسخهٔ نصب‌شده دست نمی‌خورد.

این ریپازیتوری خصوصی است. نصب‌کننده فقط وقتی می‌تواند بیلد را دانلود کند که اکانت گیت‌هاب به این ریپازیتوری دسترسی داشته باشد.

## ساخت از سورس

- ویندوز ۱۰ یا ۱۱، یا مک، یا لینوکس
- [Rust](https://rustup.rs)
- در ویندوز: ابزار MSVC و SDK ویندوز ۱۰ یا ۱۱

```powershell
cargo build --profile dist
```

در ویندوز برنامه را از پوشهٔ نصب اجرا کن، نه از `target`. هنگام اجرا، مسیر خودش را برای شروع همراه ویندوز ثبت می‌کند.

```powershell
taskkill /im clipbox.exe /f 2>$null
mkdir "$env:LOCALAPPDATA\Programs\ClipBox" -Force
copy target\dist\clipbox.exe "$env:LOCALAPPDATA\Programs\ClipBox\"
& "$env:LOCALAPPDATA\Programs\ClipBox\clipbox.exe"
```

ساخت اول چند دقیقه طول می‌کشد.

## استفاده

با `Alt+V` بازش کن. برای جستجو تایپ کن.

| کلید | کار |
|---|---|
| تایپ | جستجو |
| `Up` / `Down` | جابه‌جایی |
| `Enter` | چسباندن در پنجرهٔ قبلی |
| `Shift+Enter` | چسباندن به صورت متن ساده |
| `Tab` | نوع بعدی: همه، متن، لینک، رسانه، فایل |
| `Right` / `Left` | پیش‌نمایش بزرگ / برگشت |
| `Ctrl+P` | سنجاق یا برداشتن سنجاق |
| `Del` | حذف |
| `Ctrl+Z` | برگرداندن حذف |
| `Ctrl+,` | تنظیمات |
| `Esc` | پاک کردن جستجو، بعد مخفی شدن |

با ماوس: کلیک برای انتخاب، دابل‌کلیک برای چسباندن، کلیک راست برای سنجاق، اسکرول برای حرکت در فهرست.

## تنظیمات

`Ctrl+,` را بزن. با `Up` / `Down` تنظیم را انتخاب کن و با `Left` / `Right` عوضش کن.

| تنظیم | گزینه‌ها |
|---|---|
| پوسته | خودکار، تیره، روشن |
| رنگ اصلی | ۵ رنگ |
| باز شدن با | `alt+v`، `ctrl+shift+v`، `ctrl+alt+v`، `alt+c`، ``ctrl+` `` |
| اجرا هنگام روشن شدن | روشن، خاموش |
| نگه داشتن تاریخچه | همیشه، ۱ سال، ۳ ماه، ۱ ماه، ۱ هفته |
| رد کردن رمزها | روشن، خاموش |
| اندازهٔ متن | ۱۲، ۱۳، ۱۴ |
| تیره کردن صفحه | خاموش، کم، متوسط، زیاد |

لینک پایین تنظیمات [github.com/Amir-Pakdel](https://github.com/Amir-Pakdel) را باز می‌کند.

## حذف

1. ClipBox را باز کن، `Ctrl+,` را بزن و **اجرا هنگام روشن شدن** را خاموش کن.
2. روی آیکن سینی راست‌کلیک کن و **Exit** را بزن.
3. در ویندوز پوشهٔ `%LOCALAPPDATA%\Programs\ClipBox` را پاک کن.
4. برای پاک کردن تاریخچه و تنظیمات هم، در ویندوز `%APPDATA%\clipbox`، در مک `~/Library/Application Support/clipbox` و در لینوکس `~/.local/share/clipbox` را پاک کن.

## توسعه

```powershell
cargo run
.\run.bat
```

| فایل | کار |
|---|---|
| `src/main.rs` | جستجو، فهرست، پیش‌نمایش، تنظیمات |
| `src/store.rs` | پایگاه تاریخچه |
| `src/win.rs` | کلیپ‌بورد، میانبر، چسباندن و سینی در ویندوز |
| `src/unix.rs` | همان‌ها در مک و لینوکس |
| `src/autostart.rs` | اجرا هنگام ورود |
| `vendor/gpui` | GPUI 0.2.2 با اصلاح متن راست‌به‌چپ |
